# Phở Việt Oława — strona wizytówka

Statyczna strona restauracji Phở Việt (ul. 3 Maja 20K, Oława).

- `index.html` — cała strona (Tailwind CSS z CDN, bez kroku budowania)
- `img/` — logo, favicon i zdjęcia dań (WebP)

Podgląd lokalnie: otwórz `index.html` w przeglądarce.

Przed publikacją:
- zamienić Tailwind CDN na zbudowany plik CSS,
- w `og:image` wpisać pełny adres URL z domeną.
